# Mundo Museum

Mundo is a digital museum-curation experience. The first route is a responsive sign-in screen with an interactive artwork reveal: moving across the ancient figure uncovers its contemporary counterpart beneath the cursor.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```
